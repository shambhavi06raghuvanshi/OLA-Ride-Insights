
# OLA Ride Insights Project

## Project Overview
This project analyzes OLA ride booking data to understand ride performance, customer behavior, revenue, cancellations, and ratings.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- MySQL
- Power BI
- Streamlit

## Project Structure
- Dataset: Raw and cleaned datasets
- Python: Data cleaning and exploratory data analysis
- SQL: Business analysis queries
- PowerBI: Interactive Power BI dashboard
- Streamlit: Interactive web application

## Key Analysis
- Successful and cancelled bookings
- Ride distance by vehicle type
- Customer and driver cancellation reasons
- Revenue by payment method
- Customer and driver ratings
- Top customers by booking value

## Dashboard Pages
1. Overall
2. Vehicle Type
3. Revenue
4. Cancellation
5. Ratings

## Streamlit Application
The Streamlit application displays key performance indicators and interactive charts based on the cleaned OLA ride dataset.

## Dataset
The project uses an OLA ride booking dataset containing 103,024 records and 20 columns.
